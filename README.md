## 📝 Guide format

Each guide is written like a knowledge base article or runbook:

- **Scenario** — the issue or task at hand
- **Resolution steps** — what to do, in order
- **Why it matters** — the underlying concept, so it's not just rote steps
- **Screenshots** — walkthrough visuals where useful
